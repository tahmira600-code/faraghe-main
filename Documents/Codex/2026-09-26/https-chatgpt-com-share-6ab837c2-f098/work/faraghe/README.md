# faraghe

موقع تجريبي كيجمع الناس اللي كيقلبو على خدمة بمقدّمي الخدمات فمدنهم. الواجهة بالدارجة وكتخدم من اليمين لليسار.

## شنو موجود

- البحث حسب نوع الخدمة والمدينة.
- جدول أسبوعي لمقدّم الخدمة بأكثر من فترة فراغ لكل يوم، وبحث بتاريخ وساعة محددين.
- فلتر للمقدّمين اللي يقدرو يمشيو عند الزبون.
- ملفات مقدّمي الخدمات وصفحة مستقلة لكل ملف.
- حساب زبون أو مقدّم خدمة، وملف مهني قابل للتعديل.
- إرسال طلب خدمة، ومتابعة الحالة أو قبول الطلب من لوحة الحساب.
- وضع تجريبي بلا قاعدة بيانات، أو ربط Supabase لتسجيل حقيقي وتخزين مشترك.
- ما كاين حتى `service_role` key فالمتصفح أو فالمشروع.

## التشغيل فالوضع التجريبي

1. ثبّت Node.js إصدار 20.9 أو أحدث.
2. افتح هاد المجلد فالطرفية.
3. شغّل `npm install` ومن بعد `npm run dev`.
4. حلّ `http://localhost:3000` فالمتصفح.

إلا خليتي إعدادات Supabase فارغة، التطبيق كيستعمل حسابات وطلبات تجريبية مخزّنة فالمتصفح الحالي. هاد الوضع مناسب للتجربة فقط؛ البيانات ما كتنتاقلش بين أجهزة الناس، وما خاصوش يكون طريقة تسجيل الدخول للموقع المنشور.

## ربط Supabase

1. أنشئ مشروع Supabase ديالك.
2. من SQL Editor شغّل الملف `supabase/schema.sql`.
3. نسخ `.env.example` إلى `.env.local`.
4. حط رابط المشروع والمفتاح العام `anon` أو `publishable` فـ:

   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-public-anon-or-publishable-key
   ```

5. عاود شغّل الموقع. فعّل تأكيد البريد من إعدادات Supabase Auth إلا بغيتي الحسابات الجديدة تأكد الإيميل قبل الدخول.

المفتاح العام مصمم للاستعمال فالواجهة، والحماية كتجي من سياسات RLS الموجودة فالـ SQL. **ممنوع تحط `service_role` key فـ `.env.local` أو فالكود اللي كيوصل للمتصفح.**

## النشر والدومين

- تقدر تنشر تطبيق Next.js على خدمة كتدعم Node.js؛ إعدادات Supabase خاصها تكون مضبوطة كذلك فإعدادات البيئة ديال منصة النشر.
- الحساب اللي فيه مشروع Supabase وحساب الاستضافة والدومين خليه باسمك وبالبريد ديالك. حمّل نسخة من ملفات المشروع وخلي معلومات التجديد والدخول عندك.
- الاستضافة المجانية كتصلح للبداية ولكن ممكن تكون عندها حدود أو يتوقف الموقع حسب شروط المنصة. الدومين اللي كتشتريه سجّلو باسمك، وجدّدو قبل ما تسالي مدة التسجيل.

## هيكلة مختصرة

- `app/page.tsx` الصفحة الرئيسية والبحث.
- `app/dashboard/page.tsx` لوحة الحساب والملف المهني والطلبات.
- `app/auth/page.tsx` تسجيل الدخول وإنشاء الحساب.
- `app/providers/[id]/page.tsx` ملف مقدّم الخدمة.
- `components/app-provider.tsx` حالة الحساب والملفات والطلبات.
- `supabase/schema.sql` الجداول وسياسات الوصول.

## كيفاش خدام جدول الأوقات

مقدّم الخدمة كيضيف فلوحة الحساب الفترات اللي متاح فيها فكل يوم (مثلاً الاثنين 18:00–21:00)، ويقدر يزيد أكثر من فترة فالنهار. الزبون كيختار تاريخاً وساعة؛ البحث كيبين الملفات اللي جدولها فيه ساعة كاملة ابتداءً من الوقت المختار. إرسال الطلب ما كيعنيش أن الموعد تثبّت: مقدّم الخدمة خاصو يقبل الطلب من لوحة الحساب.
